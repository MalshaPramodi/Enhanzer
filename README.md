\# Enhanzer Full Stack Assignment — Angular \& .NET Core



Full stack web app with a login page (proxied through a .NET backend to Enhanzer's

external POS API) and a Purchase Bill form, built as a technical assessment.



\## Tech Stack



\- \*\*Frontend:\*\* Angular (latest), TypeScript

\- \*\*Backend:\*\* ASP.NET Core Web API (.NET 8)

\- \*\*Database:\*\* SQL Server



\## Prerequisites



Install these before running the project:



| Tool | Required Version | Check with |

|---|---|---|

| Node.js | 22.x LTS or higher | `node -v` |

| npm | 10.x or higher | `npm -v` |

| .NET SDK | 8.0.x | `dotnet --list-sdks` |

| SQL Server | LocalDB, Express, or full instance | — |

| Angular CLI | latest (installed via `npx`, no global install needed) | — |
